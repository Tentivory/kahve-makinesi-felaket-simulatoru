# Kahve Makinesi Felaket Simülatörü

## 🌟 Resmi Tanıtım

Bu depo, insanlık tarihinin en büyük teknolojik başarısızlıklarından birini dijital ortamda ölümsüzleştirme projesidir.

**Kahve Makinesi Felaket Simülatörü**, size hiçbir zaman kahve vermeyecek olan bir yazılımın gururla sunumudur. Her çalıştırmada %100 felaket garantisi verilmektedir.

## 🛠️ Özellikler

- Gerçekten çalışan Python kodu
- Rastgele felaket mesajları
- Dramatik beklemeler
- Sıfır kahve çıktısı
- Yüksek mizah değeri (kendi iddiamız)

## 🚀 Nasıl Kullanılır

```bash
python3 kahve_felaket.py
```

Adını yaz, enter'a bas, felaketi izle. Tekrar dene. Yine felaket. Sonsuza kadar.

## 📊 Teknik Detaylar

Bu proje, modern yazılım mühendisliğinin tüm kurallarını bilinçli olarak ihlal ederek geliştirilmiştir. Kod kalitesi "çalışıyor ya yeter" seviyesindedir.

## ⚠️ Uyarı

Bu simülatörü çalıştırdıktan sonra gerçek hayatta kahve makinesi kullanırsanız, hayal kırıklığı yaşayabilirsiniz. Çünkü gerçek makine bazen çalışır.

## 📝 Lisans

Bu proje "Ne istersen yap, ama kahve bekleme" lisansı altındadır.
